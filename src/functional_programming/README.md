- # Functional Programming

- Functional programming in Rust often uses functions, closures, and iterators to build small reusable pieces.
- Closures can capture values from their environment, including mutable borrows when needed.
- Iterators and combinators such as `map`, `filter`, and `fold` help express data processing without manual loops.
- Prefer immutable data and pure transformations when possible, and use mutation only when it improves clarity.
